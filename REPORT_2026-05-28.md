## 1. Cast-on triggers gem list

**Проблема.** В Cast on Critical / Shock / Freeze / Block / Minion Death и т.п. в дропдауне поддерживаемых слотов показывались только support-гемы, нельзя было выбрать активный spell-гем как триггер-таргет.

**Корневая причина.** `GemViewModel.AvailableGemNameItems` возвращал `SupportGemNameItems`, если `IsSupport=true`. Пустые слоты создаются с `IsSupport=true`, и Lua-данные не различали обычную группу и trigger/meta-группу.

**Что сделано.**
- `PBLEngine/LuaHost.cs::GetSkillGroups` теперь возвращает флаг `isTrigger` — проверяет первый non-support гем в `gemList`, ищет `skillTypes[SkillType.Triggers]` (32) или `[SkillType.Meta]` (122).
- `PBLEngine/ConfigOptionDto.cs::SkillGroupEntry` — добавлено поле `IsTrigger`.
- `PBLApp.Core/SkillsTabViewModel.cs`:
  - `SkillGroupViewModel.IsTrigger` (ObservableProperty);
  - `TriggerSlotGemNameItems` = `ActiveGemNameItems` ⊕ `SupportGemNameItems` (active first);
  - `IsTriggerGroup(int groupIdx)` lookup;
  - `GemViewModel.AvailableGemNameItems` отдаёт combined список, когда `IsSupport && group.IsTrigger`;
  - `CommitName` валидирует против combined списка;
  - `RebuildGroupGems` пере-запрашивает `IsTrigger` после изменения active гема (иначе флаг обновится только при следующем Refresh).
- `LocalizationService.LanguageChanged` пересобирает `TriggerSlotGemNameItems`.

**Verify.**

```

```

**Выводы.**

- `runCallback('OnFrame')` + `BuildOutput` — 50-70 ms, могут быть **deferred**.

### Pen/Brush cache (#5)

Уже сделано в `TreeCanvas.cs:118-179`: 30+ `static readonly IBrush/IPen`. Per-frame аллокаций нет.

### Debounce (#6)

**Что сделано.**
- `PBLEngine/LuaHost.cs`:
  - `AllocNode(nodeId, deferRecalc=false)` / `DeallocNode(nodeId, deferRecalc=false)` — при `deferRecalc=true` пропускают `runCallback('OnFrame')` и `BuildOutput`;
  - новый `RecalcStats()` — собственно `OnFrame` + `BuildOutput`, вызывается из дебаунса.
- `PBLApp.Core/TreeTabViewModel.cs`:
  - `System.Timers.Timer _statsDebounce(120, AutoReset=false)`;
  - `AllocNodeAsync` / `DeallocNodeAsync` теперь вызывают `_host.AllocNode(id, deferRecalc: true)` и `ScheduleStatsRefresh()`;
  - дебаунс перезапускается на каждый клик внутри окна 120 ms;
  - по истечении дебаунса: `RecalcStats()` + `_onStatsChanged()` через `SynchronizationContext` обратно на UI-поток.

**Замеры (5 последовательных кликов).**

| Сценарий | Время | Per-click |
|----------|-------|-----------|
| Старый путь (full) | 847 ms | ~170 ms |
| Новый (deferred) | 664 ms (598 ms alloc + 66 ms recalc) | ~120 ms |
| **Saved** | **-183 ms (-22%)** | **-30%** |

Сама первая отрисовка allocated-цвета ноды происходит сразу — debounce задерживает только sidebar/Calcs обновление на ~120 ms после последнего клика серии.

## 7. Magic-item base parser boundary

**Проблема.** `TryTranslateMagicName` в `GameTranslationService.cs` искал base name внутри строки используя `' '` как границу слова. Это:
1. Не различает базы рядом с пунктуацией (`Belt,` / `Ring.`);
2. Может матчить `Ring` внутри слова `Ringmaster` если бы такое встретилось.

**Что сделано.**
```csharp
static bool IsWordChar(char c) => char.IsLetterOrDigit(c) || c == '\'';
// Boundary: !IsWordChar(prevChar) && !IsWordChar(nextChar)
```
Цикл переписан с поддержкой нескольких вхождений ключа в строку (`IndexOf(k, searchFrom)`).
Longest-match сохраняется, так что `Heavy Belt` побеждает `Belt`.

## 10. Missing unique icons (44/47)

**Подход.**
1. CDN `cdn.poe2db.tw/gen/image/...` возвращает 403 для этих 47 уников.
2. На странице `poe2db.tw/us/<slug>` присутствует `web.poecdn.com/gen/image/<base64>/<hash>/Name.png` — официальный GGG CDN с серверной подписью.
3. Скрипт `tools/fetch_missing_uniques.mjs`:
   - читает `missing.json::uniques`;
   - slugify имя (`Doedre's Tenure` → `Doedres_Tenure`);
   - GET poe2db item page;
   - regex extract signed `web.poecdn.com` URL;
   - download to `PBLExport/icons/cache/<file path with .png>`;
   - update `icon_map.json`.

**Результат.**
- 44/47 ok (Queen of the Forest, Headhunter, Bones of Ullr, Kalandra's Touch, Ming's Heart, Carnage Heart, …).
- 3 failures: `Sekhema's Resolve Cold/Fire/Lightning` — page-404 на poe2db, скорее всего slug отличается ("Sekhemas_Resolve" + element subpath). Можно дотащить ручным маппингом позже.

**Csproj fix.** `PBLApp/PBLApp.csproj`: `Include="..\PBLExport\icons\cache\**\*.webp"` → `\*.*` (теперь захватывает и `.png` файлы из этого батча — но Avalonia Bitmap всё равно сниффит формат по magic-bytes, расширение не важно).

Canvas-стиль: предметы на своих позициях, без сетки

Слоты — фиксированные пиксельные прямоугольники игровых размеров, расположены свободно с естественными промежутками. Никакого "вытягивания" под клетки.
Game cell unit = 50 dip. Helmet 2×2 = 100×100, Body 2×3 = 100×150, Weapon 2×4 = 100×200, Belt 2×1 = 100×50, Amulet/Ring/Charm 1×1 = 50×50, Flask 1×2 = 50×100, Gloves/Boots 2×2 = 100×100.

Главные отличия от прошлой реализации

  • Никаких Grid — переход на Canvas с Canvas.Left/Canvas.Top/Width/Height
  • Предметы не "вытягиваются" под клетки — у каждого слота своё фиксированное соотношение сторон
  • Между группами слотов — естественные промежутки (40-60 dip), не равномерная решётка
  • Drag-drop по-прежнему через Tag на Border'ах

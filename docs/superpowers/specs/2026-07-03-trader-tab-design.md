# Вкладка «Трейдер»: поиск апгрейдов на торговой площадке PoE2

**Дата:** 2026-07-03
**Статус:** одобрено (дизайн), готово к плану реализации

## Цель

Пользователь выбирает слот экипировки — приложение ищет на pathofexile.com/trade2
предметы, которые улучшат билд (запрос взвешен по вкладу модов в DPS/EHP, как
PoB Trader в оригинале), и показывает результаты с ценами, приростом статов и
возможностью «примерить» предмет в билд.

## Решения, принятые с пользователем

- **Сценарий:** поиск апгрейдов по слоту (аналог PoB Trader). Поиск «похожих на
  конкретный предмет» — вне скоупа этой итерации.
- **UI:** отдельная вкладка «Трейдер» рядом с Items/Tree/Skills.
- **Действия с результатом:** примерить в билд, Δ DPS/EHP прямо в таблице,
  whisper в буфер, открыть запрос на trade-сайте.
- **Авторизация:** OAuth-логин через pathofexile.com (client_id=pob, PKCE) для
  in-app результатов + fallback «открыть на trade-сайте» без логина.
- **Архитектура:** DownloadPage-шим в C#; весь Lua-код трейдера
  переиспользуется как есть.

## Архитектура

**Принцип:** Lua-классы `TradeQueryGenerator`, `TradeQueryRequests`,
`TradeQueryRateLimiter`, `TradeHelpers` работают без изменений. Класс
`TradeQuery.lua` (UI-попап оригинала) **не используется** — только headless-части.
Это минимизирует конфликты при upstream-sync.

C# добавляет четыре компонента (PBLEngine):

### 1. DownloadPageShim
Реализация `launch:DownloadPage(url, callback, params)` поверх `HttpClient`:
- `params.body` задан → POST, иначе GET; `params.header` — строка(и) заголовков
  как в оригинале (разделитель `\n`).
- Ответ — таблица `{body, header}`; `header` содержит сырые заголовки ответа,
  включая `X-Rate-Limit-*` и статус-строку `HTTP/1.1 NNN` (их парсит Lua
  rate limiter — формат должен совпасть с оригинальным SimpleGraphic).
- Callback вызывается **строго на Lua-потоке** через очередь завершений
  (drain в TraderPump); `errMsg` при сетевой ошибке / не-2xx.
- Стаб `lcurl.safe` в `PBLEngine/lua/compat.lua`: `Data/QueryMods.lua` уже
  закоммичен, живой curl генератору не нужен (регенерация QueryMods — отдельный
  сценарий, вне скоупа).

### 2. TraderPump
Таймер ~150 мс на Lua-диспетчере — замена кадрового цикла оригинала:
- шаг корутины генератора (`tradeQueryGenerator:OnFrame()`) — по образцу
  BuildNodePower: прогресс + отмена;
- `tradeQueryRequests:ProcessQueue(onRateLimit)`;
- drain очереди HTTP-завершений (вызов Lua-callback'ов).
Активен только пока открыта вкладка или идёт незавершённая работа.

### 3. TraderService (C#-фасад над Lua)
- `GenerateQueryAsync(slot, weights, options, progress, ct)` →
  `TradeQueryGenerator:StartQuery` со стабом `queryTab = {itemsTab = ...}`;
  результат — query JSON.
- `SearchAsync(league, queryJson)` / `FetchAsync(...)` → `TradeQueryRequests`
  (weight-adjusted повтор при >10k результатов и батчи fetch по 10 — внутри Lua).
  Результат: список `{itemText, цена, валюта, whisper, продавец}`.
- `ComputeDiffsAsync(itemTexts, ct)` — для каждого результата: Item из raw-текста
  → `calcFunc({repItem})` → Δ выбранных статов. Батчами, в фоне, отменяемо.
- Лиги: `GET https://www.pathofexile.com/api/leagues?type=main&compact=1`
  (без SSF) — напрямую в C#.
- Курсы валют: poe.ninja, кэш 1 час — напрямую в C#.

### 4. PoeOAuthService
- PKCE (S256), `client_id=pob`, scope как в оригинале (включая `account:trade`);
  системный браузер + `HttpListener` на `localhost:<случайный порт>`.
- Обмен кода на токен — напрямую `HttpClient` (не через Lua).
- Токены (access/refresh/expiry) хранятся в настройках приложения и
  **инжектятся в Lua `main.api`** — refresh-цикл дальше делает существующий
  `PoEAPI:ValidateAuth` через шим.

### Поток данных
1. Открытие вкладки → подгрузка лиг → выбор лиги/весов.
2. «Найти апгрейды» у слота → генератор корутиной взвешивает моды
   (прогресс-бар, отмена) → query JSON.
3. Search POST → id результатов → fetch батчами → строки с ценами появляются
   сразу.
4. Фоном считаются Δ DPS/EHP → колонки заполняются по мере готовности →
   сортировка по умолчанию «прирост/цена».
5. Действия: примерить / whisper / открыть на сайте.

## UI (PBLApp.Core + PBLApp)

`TraderTabViewModel` + `TraderTabView`, домашний стиль (boxed-ячейки,
BgSurface/BorderSubtle/radius6/h36).

- **Шапка:** лига (реалм фиксирован poe2), статус входа («Войти через
  pathofexile.com» / аккаунт + выход), суммарная стоимость примеренного в дивинах.
- **Панель весов:** пресеты «DPS / Выживаемость / Баланс» + редактируемые
  множители (FullDPS, TotalEHP), лимит цены + валюта.
- **Таблица слотов** (18 базовых слотов оригинала): кнопка «Найти апгрейды»
  (стадии: генерация → поиск → диффы; отменяемо), счётчик результатов.
- **Результаты слота:** цена (+ в дивинах), Δ DPS, Δ EHP, прирост/цена,
  продавец; сортировка по колонкам. Кнопки: «Примерить» (импорт itemText в пул
  существующим механизмом + в слот, откат Undo), «Whisper» (буфер обмена),
  «Открыть на trade-сайте» (`.../trade2/search/poe2/<league>?q=<json>`).
- **Тултип результата** — существующий пайплайн тултипов с переводом модов.

## Ошибки и деградация

- Не залогинен: генерация query и «Открыть на сайте» работают; in-app поиск
  задизейблен с подсказкой.
- 401 → сброс токена, кнопка входа. 429 → бэкофф rate limiter'а, в статус-строке
  «лимит запросов, ждём N с».
- Сетевые ошибки — нотис в строке слота, не модалка.
- Отмена на любой стадии оставляет чистое состояние (по образцу BuildNodePower).

## Тестирование

- xUnit (без сети): DownloadPageShim с фейковым handler (заголовки доходят до
  Lua-таблицы, callback на Lua-потоке, POST/GET по body); PKCE-параметры OAuth;
  парсинг poe.ninja; генератор на фикстурном билде выдаёт валидный query JSON
  (`stats[0].type == "weight"`, ≤35 фильтров).
- MCP-инструменты `visual_trader_*` (открыть вкладку, состояние, запустить
  поиск) для скриншот-верификации.
- Финал — `/pbl-verify` со скриншотом вкладки.

## Локализация

Все строки вкладки — через существующий loc-пайплайн (RU/EN). Моды предметов в
результатах переводятся существующим пайплайном перевода модов (тултип/примерка).

## Вне скоупа

- Поиск уникальных предметов по имени / «похожих на текущий предмет».
- Jewel-слоты дерева и кластерные джемы.
- Автопокупка, история цен, live-search.
- Регенерация `Data/QueryMods.lua` из приложения (только внешний сценарий).

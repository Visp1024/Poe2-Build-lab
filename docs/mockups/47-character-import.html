#47 — Импорт персонажа из игры

Загрузка персонажа с аккаунта pathofexile.com (OAuth уже есть в приложении — им пользуется «Трейдер», scope account:characters уже запрошен). Разбор дерева/предметов/умений делает существующий Lua (ImportTab:ImportPassiveTreeAndJewels / ImportItemsAndSkills) — переписывать парсинг не нужно. Ниже два варианта размещения UI. Оба показывают одни и те же состояния.
Вариант A — отдельное окно «Импорт персонажа»
  • Открывается из двух мест: карточка «Создать билд» в списке и кнопка в открытом билде.
  • Из списка билдов создаёт новый билд по персонажу, из билда — импорт в текущий.
  • Место под будущее: обновление билда «одной кнопкой» (переимпорт того же персонажа).

В карточку «Создать билд» добавляется вторая строка действия — «Импорт персонажа». Она создаёт новый файл билда, названный по имени персонажа, и сразу его открывает (так же, как сейчас работает импорт из кода).

Что под капотом (одинаково для A и B)

1. Токен — существующий PoeOAuthService (+ обновление по refresh_token).
2. GET api.pathofexile.com/character/poe2 — список; /character/poe2/<имя> — сам персонаж.
3. JSON уходит в Lua: build.importTab:ImportPassiveTreeAndJewels / ImportItemsAndSkills — тот же код, что в оригинальном PoB, флажки «удалять…» проставляются из C#.
4. Пересчёт и обновление вкладок Дерево / Предметы / Умения.

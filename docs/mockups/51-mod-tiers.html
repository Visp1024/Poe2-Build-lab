#51 — грейд (тир) модификаторов рядом с модами

Три варианта подачи «префикс / суффикс + тир». Данные тира берутся из пула модов базы (data.itemMods.Item, группировка по statOrder, как в крафт-панели оригинального PoB). T1 — лучший тир.

AКак в игре — строка-заголовок над модом

Точная калька с PoE2 «advanced mod descriptions»: серая строка «Префикс «Flaring» (Тир 3)», под ней сам мод. Максимально узнаваемо, но тултип становится вдвое выше.

BКомпактный бейдж слева — P3 / S5

Одна строка на мод: цветной бейдж «P3» (синий префикс) / «S5» (зелёный суффикс) / «I» (имплицит) / «C» (порча). Высота тултипа не растёт, буква + цвет уже используются в редакторе предметов — единый язык.

CТир отдельной колонкой справа

Мод слева, «Преф. T3» справа по краю. Читается как таблица, не мешает тексту мода, но требует ширины и на длинных модах колонка «уезжает».

Где показывать

Предлагаю: тултип предмета (наведение и панель экипировки), редактор предмета (строки выбранных модов + список доступных модов), результаты поиска в окне трейдера. Уники/имплициты тира не имеют — там только буква-бейдж без цифры.
